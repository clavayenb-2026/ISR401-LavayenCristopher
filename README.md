# Repositorio de la Tarea FORM-TL-01

Este repositorio contiene los archivos fuente y el documento compilado correspondientes a la actividad formativa **FORM-TL-01** de la asignatura **Ingeniería de Requerimientos (ISR-401)** de la Universidad Técnica Estatal de Quevedo (UTEQ).

## Estructura del Repositorio
- `FORM-TL-01/main.tex`: Código fuente principal en LaTeX.
- `FORM-TL-01/main.pdf`: Documento PDF final compilado.

## Instrucciones para la Reproducción
Para regenerar el documento PDF a partir del código fuente:
1. Utilizar el compilador **pdfLaTeX** (disponible en Overleaf o distribuciones TeX locales).
2. Abrir el archivo principal ubicado en la ruta `FORM-TL-01/main.tex`.
3. Asegurarse de tener las dependencias de paquetes estándar (`inputenc`, `babel`, `longtable`, `cite`).
4. Compilar ejecutando: `pdflatex main.tex`.
