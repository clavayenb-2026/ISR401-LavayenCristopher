# Evidencias propias

Las capturas proceden del portal móvil Activa Claro, abierto desde un navegador en un teléfono:

- `captura1.png`: portada, paquetes destacados y accesos.
- `captura2.png`: listado de paquetes y filtros.
- `captura3.png`: menú general de servicios.

El número de línea se ocultó para que los archivos puedan publicarse sin exponerlo.
