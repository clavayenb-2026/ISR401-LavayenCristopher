# FORM-TL-01: Taller de tipos de requisitos

## Instrucciones de Compilación
Para reproducir el PDF de este proyecto, siga estas instrucciones:

- **Compilador:** pdfLaTeX
- **Archivo principal:** main.tex
- **Dependencias:** Distribución TeX Live o MiKTeX. Paquetes requeridos: `cite`, `babel`, `inputenc`.
- **Orden de comandos:**
  1. `pdflatex main.tex`
  2. `bibtex main`
  3. `pdflatex main.tex`
  4. `pdflatex main.tex`
